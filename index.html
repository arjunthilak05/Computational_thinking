Boolean Logic: True or False

In computer science, everything boils down to True or False. This is called Boolean logic!

✓
TRUE
• 5 > 3
• 10 == 10
• "Hello" != "Bye"
• Light is ON
✗
FALSE
• 3 > 5
• 10 == 15
• "Cat" == "Dog"
• Light is OFF
💡 Everything is True or False! Is the door open? (True/False) Is it raining? (True/False) Did you win? (True/False)

Logical Operators: AND, OR, NOT

Combine multiple conditions using logical operators!

# AND - Both must be True age = 16 has_license = True if age >= 16 AND has_license: print("Can drive!") # Only if BOTH are True # OR - At least one must be True is_weekend = True is_holiday = False if is_weekend OR is_holiday: print("No school!") # True if EITHER is True # NOT - Flips True to False (and vice versa) is_raining = False if NOT is_raining: print("Go outside!") # Runs because NOT False = True

🌳 Decision Trees

What are Decision Trees?

A decision tree is a flowchart-like structure where you make decisions based on questions, and each answer leads to a different path!

🌦️ Is it raining?
↙ YES          NO ↘
☂️ Bring umbrella
↓
🚶 Go outside
☀️ Is it sunny?
↙ YES   NO ↘
🕶️ Wear sunglasses
😊 Just go!
🌳 Decision trees help you break down complex decisions into simple yes/no questions!

Real-World Decision Tree Examples

🎮 Game: Should character attack?
Is enemy nearby? → YES
  → Is health > 50%? → YES → ATTACK!
  → Is health > 50%? → NO → RUN AWAY!
Is enemy nearby? → NO → EXPLORE
🎬 Netflix: What to recommend?
Likes action movies? → YES
  → Watched Marvel? → YES → Recommend DC movies
  → Watched Marvel? → NO → Recommend superhero movies
Likes action movies? → NO → Check other genres

🧩 Simple Logic Puzzles

Classic Logic Puzzles

🧩 Puzzle 1: The Light Switch
You have 3 light switches outside a room. Only ONE controls the light bulb inside. You can flip switches, then enter the room ONCE. How do you figure out which switch controls the bulb?
Click for solution 💡
1. Turn switch #1 ON for 5 minutes, then turn it OFF
2. Turn switch #2 ON
3. Leave switch #3 OFF
4. Enter the room:
  • If bulb is ON → Switch #2
  • If bulb is OFF but WARM → Switch #1
  • If bulb is OFF and COLD → Switch #3
🧩 Puzzle 2: River Crossing
A farmer needs to cross a river with a fox, a chicken, and a bag of grain. The boat can only carry the farmer + ONE item. If left alone:
• Fox will eat the chicken
• Chicken will eat the grain
How does the farmer get everything across?
Click for solution 💡
1. Take chicken across → Leave chicken
2. Go back, take fox across
3. Bring chicken BACK with you
4. Leave chicken, take grain across
5. Go back, take chicken across
Done! ✓
